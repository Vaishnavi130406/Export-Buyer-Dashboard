# 🌍 Export Buyer Dashboard

**A Smart B2B Export Buyer Discovery and Email Marketing Platform**

## 📌 Project Overview

Export Buyer Dashboard is a web-based B2B platform designed to simplify the process of finding international buyers, managing business leads, and conducting email marketing campaigns.

The platform helps exporters search for potential buyers based on product requirements and geographical locations such as country, state, and city. It provides a centralized dashboard to manage buyer information, track email campaigns, and organize customer relationships.

The main objective is to make international buyer discovery and export business development easier, faster, and more organized.

## 🚀 Key Features

### 1. 📊 Dashboard
- View overall business and buyer statistics.
- Monitor buyer discovery activities.
- Track email campaign performance.
- Access important business information from one place.

### 2. 🔍 Buyer Search
- Search international buyers based on assigned products.
- Filter buyers by country, state, and city.
- Discover potential importers and business customers.
- View available buyer and company information.

### 3. 👥 Buyer Management
- Manage collected buyer information.
- View buyer details in an organized table.
- Maintain a centralized buyer database.
- Organize potential business contacts.

### 4. 📧 Email Campaign
- Create customized email campaigns.
- Select buyers for targeted email outreach.
- Add email subjects and message content.
- Upload product catalogue or other attachments.
- Send emails to selected buyers.

### 5. 🤝 Lead CRM
- Organize potential customers and business leads.
- Manage buyer relationships.
- Track lead information and follow-up activities.

### 6. 📜 Email History
- Maintain email campaign records.
- Review previous email activities.
- Track communication history.

### 7. ⚙️ Settings
- Manage application settings.
- Configure platform preferences.

### 8. 📈 Reports
- Access business and email activity reports.
- Monitor important performance information.

## ⚙️ Installation and Setup

### Prerequisites

Install the following before running the project:

- Python
- Node.js and npm
- Visual Studio Code
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/Vaishnavi130406/Export-Buyer-Dashboard.git
```

Navigate to the project directory:

```bash
cd Export-Buyer-Dashboard
```

### Step 2: Backend Setup

Navigate to the backend folder:

```bash
cd backend
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the backend:

```bash
python app.py
```

### Step 3: Frontend Setup

Open another terminal and navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the frontend development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

## 🔄 Application Workflow

1. Open the Export Buyer Dashboard.
2. Navigate to the Buyer Search section.
3. Search for the product assigned by the team leader.
4. Enter the target country, state, and city.
5. Retrieve the available international buyer information.
6. Review and manage the buyer details.
7. Select relevant buyers for email campaigns.
8. Prepare customized emails with product information and attachments.
9. Send emails to potential buyers.
10. Track communication activities through Email History and CRM.
